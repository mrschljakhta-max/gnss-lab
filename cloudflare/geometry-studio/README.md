# Geometry Studio — безкоштовна хмарна бібліотека для Полі

**Сайт:** https://mrschljakhta-max.github.io/gnss-lab/geometry-studio/

## Що працює без Cloudflare

Через меню «Файл» → **«Мої креслення»** можна без акаунтів і оплати:
- зберігати креслення в IndexedDB;
- відкривати, перейменовувати, дублювати та видаляти проєкти;
- бачити їхні мініатюри і продовжувати роботу після перезавантаження;
- автоматично зберігати відкритий проєкт локально приблизно кожні 4,5 секунди.

Редактор, як і раніше, веде чернетку у localStorage. Важливі креслення додатково зберігай у JSON: очищення даних сайту знищить локальну бібліотеку.

## Як підключити новий Cloudflare Free — без командного рядка

Потрібні тільки **Workers Free + D1 Free**. Нові користувачі реєструються за кодом запрошення; гості переглядають опубліковані креслення без реєстрації.

1. У новому акаунті Cloudflare відкрий **Storage & databases → D1 SQLite Database → Create database**. Назва: **geometry-studio-db**.
2. У базі відкрий **Console**. Виконай повністю SQL із файлу [migrations/0001_init.sql](./migrations/0001_init.sql). Мають з’явитися таблиці users, sessions, projects.
3. У **Compute → Workers & Pages → Create application → Create Worker** створи Worker з назвою **geometry-studio-cloud** на Free.
4. Натисни **Edit Code**, заміни стартовий код повним вмістом [worker.js](./worker.js) і натисни **Deploy**.
5. На сторінці Worker відкрий **Bindings → Add binding → D1 database**. Назва змінної **DB** (великі літери), база — **geometry-studio-db**. Збережи та розгорни зміну.
6. У **Settings → Variables and Secrets** додай секрет **INVITE_CODE**: власний випадковий код від 16 символів. Не зберігай його в GitHub, не передавай у чат. Застосуй зміни.
7. Перевір адресу Worker у браузері, додавши до неї /api/health. Має з’явитися JSON із ok:true.
8. Відкрий Geometry Studio → **Мої креслення → Налаштування хмари Cloudflare**, встав адресу Worker **без /api/health** та натисни **Підключити Worker**.
9. Введи логін латиницею (3–32 символи), пароль не менше 12 символів і секретний код запрошення → **Зареєструватися**. Тепер збереження поточного креслення синхронізує його з D1.
10. Для того, щоб гостьові посилання працювали на будь-якому пристрої, встанови адресу Worker у [geometry-studio/cloud-config.js](../../geometry-studio/cloud-config.js) як значення apiBase та збережи файл у GitHub.
11. Відкрий креслення → **Поділитися** → надішли скопійоване посилання. Воно відкриється на окремій сторінці view.html?share=… лише для перегляду. **Закрити доступ** відкликає публікацію.

Не активуй Paid заради цієї функції. Якщо з’явиться вікно оплати, зупинися та перевір умови тарифу.

### Додатковий спосіб: Wrangler CLI

Для повторюваних розгортань є [wrangler.jsonc](./wrangler.jsonc). Заміни REPLACE_WITH_D1_DATABASE_ID на UUID створеної бази та виконай з каталогу cloudflare/geometry-studio:

    npx wrangler d1 migrations apply geometry-studio-db --remote
    npx wrangler deploy
    npx wrangler secret put INVITE_CODE

Якщо ти вже вручну виконав SQL у D1 Console, повторювати міграцію не потрібно. У Wrangler-конфігурації доданий обмежувач спроб входу AUTH_LIMITER; якщо Worker створено через панель вручну, цього binding не буде, але авторизація та збереження працюватимуть.

## API, доступ та синхронізація

| Метод | Шлях | Доступ |
|---|---|---|
| POST | /api/auth/register | За кодом запрошення |
| POST | /api/auth/login | Зареєстрований користувач |
| POST | /api/auth/logout | Власник сесії |
| GET | /api/me | Власник сесії |
| GET/POST | /api/projects | Лише власник |
| GET/PUT/DELETE | /api/projects/:id | Лише власник |
| POST | /api/projects/:id/share | Лише власник |
| GET | /api/share/:shareId | Будь-хто з чинним посиланням |

Паролі зберігаються тільки у вигляді хешів, а сесії мають випадкові токени зі строком дії. Зміни інших користувачів відокремлені, а спроба перезаписати застарілу версію повертає конфлікт. Браузерна взаємодія API обмежена походженням основного сайту. Публічний перегляд віддає тільки SVG без приватної моделі.

Завантажені кимось раніше файли SVG або PNG **не можна відкликати**. Вимкнення посилання блокує лише подальший перегляд через хмару.

На проєкт діє обмеження: JSON до 750 КБ, SVG до 350 КБ, 200 проєктів на користувача. Відкритий проєкт зберігається локально кожні ~4,5 с, а при авторизації синхронізується вручну або приблизно раз на хвилину. При збоях хмари локальна копія залишається.

## Тести

Файл [worker.test.mjs](./worker.test.mjs) містить сценарії SQLite: реєстрація, вхід, відокремлені акаунти, версії, загальний доступ та його відкликання. Для Node 22:

    node --test cloudflare/geometry-studio/worker.test.mjs

**Увага:** код у GitHub не розгортає Worker сам по собі. Поки D1, Worker і секрет не підключені у твоєму новому Cloudflare-акаунті, працюватиме локальна бібліотека; хмарна синхронізація залишатиметься вимкненою.
