# Geometry Studio — креслення без реєстрації та входу

**Сайт:** https://mrschljakhta-max.github.io/gnss-lab/geometry-studio/

## Принцип доступу

Відвідувачі відкривають Geometry Studio без логіна, пароля, інвайтів чи реєстрації. Кожне креслення зберігається локально у браузері (IndexedDB), а якщо Cloudflare Worker налаштований — також у D1. Користувач отримує **два різні посилання**:

- **Для перегляду:** https://mrschljakhta-max.github.io/gnss-lab/geometry-studio/view.html?share=… — можна надіслати будь-кому, редагування недоступне, посилання можна відкликати.
- **Для редагування:** https://mrschljakhta-max.github.io/gnss-lab/geometry-studio/#edit=ID.EDITKEY — секретне посилання, хто ним володіє, той може редагувати та видаляти креслення. Не публікуй його.

Ключ редагування генерується випадково (256 біт) на сервері, його SHA-256 зберігається у D1, а сам ключ — лише в локальному IndexedDB і приватному посиланні у фрагменті URL. Він не відправляється на сервер у параметрах адреси. Якщо втратити ключ та локальну бібліотеку, сервер не зможе відновити право редагування. Для важливих креслень зберігай окремий JSON-файл та приватне посилання у менеджері паролів.

Хмара не потрібна для роботи редактора та локального збереження. Автозбереження виконується приблизно кожні 4,5 секунди, а спроба синхронізувати локальні зміни — приблизно раз на хвилину. PDF, PNG, Excel та JSON залишаються доступними.

## Налаштування Cloudflare Workers Free + D1 Free

База geometry-studio-db і Worker geometry-studio-cloud вже створювалися через панель Cloudflare. Для **анонімного** режиму потрібно два останні кроки.

**Крок 1 — оновлення схеми D1.**

1. Відкрий Cloudflare → Storage & databases → D1 SQLite Database → geometry-studio-db → **Console**.
2. Скопіюй весь SQL із [migrations/0002_guest_projects.sql](./migrations/0002_guest_projects.sql) і виконай **Execute**.
3. Команда /tables має показати додатково guest_projects та guest_rate_limits. Старі users, sessions, projects лишаються і не видаляються — це захищає вже наявні дані.

**Крок 2 — оновлення коду Worker.**

1. Відкрий Cloudflare → Workers & Pages → **geometry-studio-cloud** → **Edit code**.
2. Замінюй увесь код на **актуальний повний** вміст [worker.js](./worker.js). Натисни **Deploy**.
3. Перевір https://geometry-studio-cloud.lavash-squad.workers.dev/api/health — очікується JSON із ok:true.

Для гостьового режиму **не потрібен INVITE_CODE**. Код входу/реєстрації старого API збережений тільки заради сумісності, але сайт його більше не показує. Можна не створювати цей секрет.

Сайт уже містить [cloud-config.js](../../geometry-studio/cloud-config.js) з адресою Worker. Після оновлення двох файлів у Cloudflare можна відкривати «Мої креслення» → «Зберегти в хмарі» → «Поділитися».

### Обмеження безкоштовної хмари та захист

Для захисту бюджету D1 новий анонімний API лімітує створення до 12 проєктів на одну IP-адресу за добу, зміни — до 120 за годину, загальну кількість гостьових проєктів — до 500. Розмір однієї моделі — до 400 КБ і SVG — до 150 КБ. Ліміти перевіряються сервером, але не є повним захистом від цілеспрямованих ботів або багатьох IP-адрес; перед великою публікацією корисно додати Cloudflare WAF / Turnstile, якщо це доступно на Free.

Редагування / видалення потребує ключа, а не лише ID креслення. Публічне посилання на перегляд віддає лише назву й зображення SVG; приватна геометрична модель не публікується.

## Відкриття креслення з публічного посилання у редакторі

Публічний перегляд за адресою `view.html?share=…` тепер містить **«Редагувати копію»**. Ця кнопка відкриває `?copy=shareId`, завантажує **модель креслення** (не лише зображення SVG) і створює **новий локальний проєкт**, який не має ключа редагування оригіналу.

Редаговані копії доступні будь-кому з чинним посиланням на перегляд: публікація тепер дозволяє також копіювати геометричну модель. Якщо це небажано, не публікуй приватне креслення. Оригінал змінюється лише за окремим приватним посиланням `#edit=…`.

Після відкликання публічного посилання API перестає віддавати і SVG, і модель для копіювання. Раніше зроблені локальні копії віддалено не видаляються.

Для роботи нової кнопки потрібно ще раз **оновити повний код Cloudflare Worker** з `worker.js` через **Edit code → Deploy**, оскільки Worker не підключено до автоматичного розгортання з GitHub. Нових SQL-таблиць створювати не потрібно.

## API нового гостьового режиму

| Метод | Шлях | Доступ |
|---|---|---|
| POST | /api/guest/projects | Будь-хто з дозволеного сайту, з квотами |
| GET | /api/guest/projects/:id | Тільки з X-Edit-Key |
| PUT | /api/guest/projects/:id | Тільки з X-Edit-Key, із перевіркою revision |
| DELETE | /api/guest/projects/:id | Тільки з X-Edit-Key |
| POST | /api/guest/projects/:id/share | Тільки з X-Edit-Key |
| GET | /api/share/:shareId | Для всіх за чинним посиланням, тільки SVG |
| GET | /api/share/:shareId/copy | Для всіх за чинним посиланням, геометрична модель для незалежної копії |

Публічний перегляд не дозволяє змінювати оригінал. Відкликання посилання не видаляє копії SVG/PNG, які інші люди могли завантажити раніше.

Для перевірки схеми і API використай команду: node --test cloudflare/geometry-studio/worker.test.mjs (Node 22+ з підтримкою node:sqlite). За наявності обмежень GitHub Actions тести можна запускати локально.

**Важливо:** зміни в GitHub не оновлюють Worker автоматично, бо Worker спочатку створено через Cloudflare Dashboard, а не зв'язано з GitHub. SQL міграцію та Deploy необхідно виконати в кабінеті Cloudflare.
