# Geometry Studio

Окремий статичний модуль для інженерної та нарисної геометрії.

**Адреса GitHub Pages:** https://mrschljakhta-max.github.io/gnss-lab/geometry-studio/

## Можливості
- Аркуш A3 (297 × 420 мм), сітка 5 × 5 мм та масштабування.
- Точки, відрізки, прямі, паралелі, перпендикуляри та точки перетину.
- Колір, товщина і тип лінії.
- Дві ортогональні проєкції просторових точок.
- Автоматична побудова задачі №5 (варіант 15) у 7 кроків.
- Збереження й відновлення креслення у JSON, вивантаження SVG та друк у PDF.
- Окремі кнопки **↓ PDF**, **↓ PNG**, **↓ Excel** у лівому меню «Файл».
- Одноклікове завантаження PDF і PNG у форматі аркуша A3 (200 dpi), зі станом сітки та усіма видимими елементами креслення.
- Експорт **.xlsx** без сторонніх бібліотек і платних API: аркуш «Точки» (назви, X/Y/Z за доступними проєкціями, координати на папері); аркуш «Відрізки» (кінці, довжина в мм, тип лінії, координати кінців).


## Вихідні координати прикладу
- A (180, 80, 10) мм
- B (70, 5, 13) мм
- C (55, 95, 65) мм
- D (100, 10, 25) мм

Для цих даних H ≈ (94.420; 17.594; 10.246) мм і DH ≈ 17.507 мм. Зверни увагу, що для точки B взято Z=13 мм, як у наданому прикладі, хоча у фотокопії значення можна прочитати неоднозначно.

## Файли
- `index.html` — інтерфейс
- `style.css` — оформлення
- `app.js` — розрахунки, креслення, взаємодія та експорт

Для локального запуску відкрий `index.html`. Сервер та сторонні платні API не потрібні.

## Експорт креслення

1. Відкрий ліве висувне меню → **Файл**.
2. Натисни **↓ PDF** для окремого PDF A3 або **↓ PNG** для зображення A3; браузер одразу завантажить файл.
3. Натисни **↓ Excel** для справжнього файлу `.xlsx`, який відкривається в Microsoft Excel. Він містить два аркуші: **Точки** та **Відрізки**.
4. Кнопка **PDF / друк** залишилася: для векторного друку PDF можна обрати «Зберегти як PDF» у системному діалозі друку.

Excel бере точки й відрізки безпосередньо з геометричних об’єктів редактора. Довжина кожного скінченного відрізка дорівнює відстані між його фактичними кінцевими точками на аркуші (мм), включно з проєкційними й допоміжними відрізками. Нескінченні прямі не мають скінченної довжини та до списку відрізків не потрапляють. Просторові координати X/Y/Z визначаються за парними проєкціями Π₁/Π₂; якщо відомості відсутні, клітинка лишається порожньою. Експорт працює локально у браузері — без серверного зберігання даних.
