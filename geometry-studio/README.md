# Geometry Studio

Окремий статичний модуль для інженерної та нарисної геометрії.

**Адреса GitHub Pages:** https://mrschljakhta-max.github.io/gnss-lab/geometry-studio/

## Можливості
- Аркуш A3 (297 × 420 мм), сітка 5 × 5 мм та масштабування.
- Точки, відрізки, прямі, паралелі, перпендикуляри та точки перетину.
- Колір, товщина і тип лінії.
- Дві ортогональні проєкції просторових точок.
- Автоматична побудова задачі №5 (варіант 15) у 7 кроків.
- Збереження й відновлення креслення у JSON, вивантаження SVG та друк у PDF.

## Вихідні координати прикладу
- A (180, 80, 10) мм
- B (70, 5, 13) мм
- C (55, 95, 65) мм
- D (100, 10, 25) мм

Для цих даних H ≈ (94.420; 17.594; 10.246) мм і DH ≈ 17.507 мм. Зверни увагу, що для точки B взято Z=13 мм, як у наданому прикладі, хоча у фотокопії значення можна прочитати неоднозначно.

## Файли
- `index.html` — інтерфейс
- `style.css` — оформлення
- `app.js` — розрахунки, креслення, взаємодія та експорт

Для локального запуску відкрий `index.html`. Сервер та сторонні платні API не потрібні.
